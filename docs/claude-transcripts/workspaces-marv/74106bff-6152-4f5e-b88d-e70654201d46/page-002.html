19	
20	## Changes
21	
22	### 1. Add `services.AddHttpClient()` in the host's service registration
23	
24	In the Marv host application (`Program.cs` or wherever the
25	`IServiceCollection` is configured), add:
26	
27	```csharp
28	services.AddHttpClient();
29	```
30	
31	This registers `IHttpClientFactory` and `HttpClient` in the DI container.
32	
33	### 2. Add `Microsoft.Extensions.Http` dependency to Marv (host)
34	
35	The host application already depends on `Microsoft.Extensions.DependencyInjection`
36	and `Microsoft.Extensions.Hosting`. Adding `Microsoft.Extensions.Http` is a
37	lightweight addition (~50KB, no transitive dependencies beyond what's already
38	present).
39	
40	## Impact
41	
42	- **Plugin authors:** Can inject `IHttpClientFactory` directly without adding
43	  the NuGet package or calling `AddHttpClient()` themselves.
44	- **Existing plugins:** No change needed. If a plugin already calls
45	  `services.AddHttpClient()` in its `ConfigureServices`, the second call is
46	  a no-op (idempotent registration).
47	- **Host binary size:** Negligible increase (~50KB).
48	
49	## Non-changes
50	
51	- This does **not** register any named or typed HTTP clients. Plugins that
52	  need custom `HttpClient` configuration (base address, default headers,
53	  retry policies) still configure them via `services.AddHttpClient<T>()` or
54	  `services.AddHttpClient("name")` in their own `ConfigureServices`.
