  1. Cache mounts on both dotnet restore and dotnet publish — persists /root/.nuget/packages across builds via BuildKit, so even when csproj changes invalidate the layer, previously downloaded packages are still available.
  2. --no-restore on the publish step — avoids a redundant restore since the previous step already handles it.

This works alongside the existing GHA layer cache (cache-from: type=gha) in the release workflow.
