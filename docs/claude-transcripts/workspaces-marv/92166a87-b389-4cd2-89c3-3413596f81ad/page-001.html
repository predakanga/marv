1	# CS-004: Bulk Channel Join
2	
3	**Source:** `downstream_suggestions/improvements.md` §5
4	**Scope:** Marv.Core
5	**Complexity:** Small-Medium
6	**Breaking changes:** None (additive API)
7	
8	---
9	
10	## Problem
11	
12	When the bot needs to join multiple channels (post-authentication, or when a
13	plugin requests joins), it currently sends individual `JOIN` commands in a
14	loop. This is slow due to outbound rate limiting and generates unnecessary
15	traffic. IRC allows comma-separated channel lists in a single `JOIN` command.
16	
17	## Changes
18	
19	### 1. Add `JoinMultipleAsync` to `IBot`
20	
21	```csharp
22	/// <summary>
23	/// Joins multiple channels in a single IRC JOIN command.
24	/// Channel names are comma-separated per RFC 2812.
25	/// </summary>
26	Task JoinMultipleAsync(
27	    IReadOnlyList<string> channels,
28	    CancellationToken ct);
29	```
30	
31	### 2. Implementation in MarvBot
32	
33	Construct a single `JOIN` command with comma-separated channel names:
34	
35	```csharp
36	public async Task JoinMultipleAsync(
37	    IReadOnlyList<string> channels, CancellationToken ct)
38	{
39	    if (channels.Count == 0) return;
40	
41	    // IRC line length limit is 512 bytes. Batch channels to fit.
42	    // "JOIN " = 5 bytes, "\r\n" = 2 bytes, leaves 505 for channel list.
43	    const int maxLineLength = 505;
44	    var batch = new List<string>();
45	    var currentLength = 0;
46	
47	    foreach (var channel in channels)
48	    {
49	        var addedLength = batch.Count == 0
50	            ? channel.Length
51	            : channel.Length + 1; // +1 for comma
52	
53	        if (currentLength + addedLength > maxLineLength && batch.Count > 0)
54	        {
55	            await SendJoinBatch(batch, ct);
56	            batch.Clear();
57	            currentLength = 0;
58	            addedLength = channel.Length;
59	        }
60	
61	        batch.Add(channel);
62	        currentLength += addedLength;
63	    }
64	
65	    if (batch.Count > 0)
66	        await SendJoinBatch(batch, ct);
67	}
68	
69	private Task SendJoinBatch(List<string> channels, CancellationToken ct)
70	{
71	    var joined = string.Join(',', channels);
72	    return SendRawAsync(new IrcMessage("JOIN", [joined]), ct);
73	}
74	```
75	
76	### 3. Use in core channel join logic
77	
78	The bot's post-authentication channel join (which iterates
79	`MarvConfiguration.Channels`) should use `JoinMultipleAsync` instead of
80	looping over `JoinAsync`.
81	
82	### 4. Channel keys
83	
84	The simple version above doesn't handle per-channel keys. Two options:
85	
86	- **Option A:** Overload that accepts `(channel, key?)` tuples. Channels
87	  with keys must be first in the JOIN command per RFC 2812.
88	- **Option B:** Only batch keyless channels. Channels with keys use
89	  individual `JoinAsync` calls.
90	
91	**Recommendation:** Option B for now. Key-protected channels are uncommon
92	in bot deployments. The primary win is batching the bulk of keyless channels.
93	
94	## Slipstream / coalescing (deferred)
95	
96	The downstream suggestion mentions a slipstream approach: maintaining a
97	pending join list and coalescing joins into a single message when flushed.
98	This is a good idea for generalization (could apply to WHO, MODE, etc.) but
99	raises layering concerns — the connection layer would need awareness of
100	pending commands.
101	
102	**Recommendation:** Defer coalescing. `JoinMultipleAsync` gives the caller
103	explicit control over batching without complicating the connection layer. If
104	coalescing proves necessary, it can be added as a connection-level feature
105	later without changing the `IBot` API.
106	
107	## Impact
108	
109	- **Plugin API:** Adds one method to `IBot`. Additive, non-breaking.
110	- **Core behavior:** Initial channel join becomes a single IRC command
111	  instead of N individual commands. Faster startup, less rate-limit
112	  pressure.
113	- **Tests:** Add unit test for batching logic (line-length splitting).
114	  Integration test for multi-channel join.

468	    private async Task HandleCap(IrcMessage message, CancellationToken ct)
469	    {
470	        if (message.Parameters.Count < 3) return;
471	
472	        var subCommand = message.Parameters[1].ToUpperInvariant();
473	        var isMultiLine = message.Parameters.Count > 3 && message.Parameters[2] == "*";
474	        var capList = message.Parameters[isMultiLine ? 3 : 2];
475	
476	        switch (subCommand)
477	        {
478	            case "LS":
479	                foreach (var cap in ParseCapList(capList))
480	                {
481	                    _capabilityManager.SetAvailable(cap.Key, cap.Value);
482	                }
483	
484	                if (!isMultiLine)
485	                {
486	                    // All capabilities listed — request the ones we want
487	                    var toRequest = DesiredCapabilities
488	                        .Where(c => _capabilityManager.IsAvailable(c))
489	                        .ToList();
490	
491	                    if (toRequest.Count > 0)
492	                    {
493	                        _logger.LogInformation("Requesting capabilities: {Caps}",
494	                            string.Join(", ", toRequest));
495	                        await SendRawAsync(new IrcMessage("CAP", ["REQ", string.Join(' ', toRequest)]), ct);
496	                    }
497	                    else
498	                    {
499	                        await SendRawAsync(new IrcMessage("CAP", ["END"]), ct);
500	
501	                    }
502	                }
503	                break;
504	
505	            case "ACK":
506	                foreach (var capName in capList.Split(' ', StringSplitOptions.RemoveEmptyEntries))
507	                {
508	                    _capabilityManager.SetNegotiated(capName);
509	                    _logger.LogDebug("Capability acknowledged: {Cap}", capName);
510	                }
511	
512	                // Start SASL if negotiated and credentials are configured
513	                if (_capabilityManager.IsNegotiated(Platform.Capabilities.Sasl)
514	                    && !string.IsNullOrEmpty(_config.SaslUser) && !string.IsNullOrEmpty(_config.SaslPassword)
515	                    && !_saslInProgress)
516	                {
517	                    _saslInProgress = true;
518	                    await SendRawAsync(new IrcMessage("AUTHENTICATE", ["PLAIN"]), ct);
519	                }
520	                else
521	                {
522	                    await SendRawAsync(new IrcMessage("CAP", ["END"]), ct);
523	
524	                }
525	                break;
526	
527	            case "NAK":
528	                _logger.LogWarning("Capabilities rejected: {Caps}", capList);
529	                await SendRawAsync(new IrcMessage("CAP", ["END"]), ct);
530	
531	                break;
532	
533	            case "NEW":
534	                foreach (var cap in ParseCapList(capList))
535	                {
536	                    _capabilityManager.AddNewCapability(cap.Key, cap.Value);
537	                }
538	                var newCaps = ParseCapList(capList)
539	                    .Where(c => DesiredCapabilities.Contains(c.Key, StringComparer.OrdinalIgnoreCase))
540	                    .Select(c => c.Key)
541	                    .ToList();
542	                if (newCaps.Count > 0)
543	                {
544	                    await SendRawAsync(new IrcMessage("CAP", ["REQ", string.Join(' ', newCaps)]), ct);
545	                }
546	
547	                var capChangedNew = CreateCapChangedEvent(message);
548	                await FanOutEventAsync(capChangedNew, ct);
549	                break;
550	
551	            case "DEL":
552	                foreach (var capName in capList.Split(' ', StringSplitOptions.RemoveEmptyEntries))
553	                {
554	                    _capabilityManager.RemoveCapability(capName);
555	                    _logger.LogDebug("Capability removed: {Cap}", capName);
556	                }
557	
558	                var capChangedDel = CreateCapChangedEvent(message);
559	                await FanOutEventAsync(capChangedDel, ct);
560	                break;
561	        }
562	    }

685	    /// <summary>
686	    /// Waits for all pending auth steps to complete, then fires ReadyEvent and
687	    /// joins channels. If auth doesn't complete within the configured timeout, proceeds anyway.
688	    /// A timeout of 0 means wait indefinitely.
689	    /// </summary>
690	    private async Task CompleteAuthSequenceAsync(CancellationToken ct)
691	    {
692	        var timeoutSeconds = _config.AuthTimeoutSeconds;
693	
694	        if (timeoutSeconds > 0)
695	        {
696	            using var timeoutCts = CancellationTokenSource.CreateLinkedTokenSource(ct);
697	            timeoutCts.CancelAfter(TimeSpan.FromSeconds(timeoutSeconds));
698	
699	            try
700	            {
701	                await _readyTcs!.Task.WaitAsync(timeoutCts.Token);
702	            }
703	            catch (OperationCanceledException) when (!ct.IsCancellationRequested)
704	            {
705	                _logger.LogWarning("Post-registration authentication timed out after {Seconds}s — proceeding", timeoutSeconds);
706	            }
707	        }
708	        else
709	        {
710	            await _readyTcs!.Task.WaitAsync(ct);
711	        }
712	
713	        var syntheticMessage = new IrcMessage(null, null, "READY", []);
714	        await FireReadyAndJoinAsync(syntheticMessage, ct);
715	    }

809	        var args = spaceIdx >= 0 ? ctcpContent[(spaceIdx + 1)..] : null;

/// <summary>
/// Simple named-pipe style stream using two underlying pipe streams.
/// </summary>
internal class Pipe
{
    private readonly MemoryStream _buffer = new();
    private readonly SemaphoreSlim _dataAvailable = new(0);
    private int _readPosition;
    private bool _completed;

    public PipeReader Reader => new(this);
    public PipeWriter Writer => new(this);

    internal class PipeReader(Pipe pipe) : Stream
    {
        public override bool CanRead => true;
        public override bool CanWrite => false;
        public override bool CanSeek => false;
        public override long Length => throw new NotSupportedException();
        public override long Position { get => throw new NotSupportedException(); set => throw new NotSupportedException(); }

        public override int Read(byte[] buffer, int offset, int count)
        {
            // Blocking read — wait for data
            pipe._dataAvailable.Wait();
            lock (pipe._buffer)
            {
                pipe._buffer.Position = pipe._readPosition;
                var bytesRead = pipe._buffer.Read(buffer, offset, count);
                pipe._readPosition += bytesRead;
                if (bytesRead > 0) pipe._dataAvailable.Release();
                return bytesRead;
            }
        }

        public override async Task<int> ReadAsync(byte[] buffer, int offset, int count, CancellationToken ct)
        {
            await pipe._dataAvailable.WaitAsync(ct);
            lock (pipe._buffer)
            {
                pipe._buffer.Position = pipe._readPosition;
                var bytesRead = pipe._buffer.Read(buffer, offset, count);
                pipe._readPosition += bytesRead;
                if (bytesRead > 0 || pipe._completed) pipe._dataAvailable.Release();
                return bytesRead;
            }
        }

        public override void Flush() { }
        public override long Seek(long offset, SeekOrigin origin) => throw new NotSupportedException();
        public override void SetLength(long value) => throw new NotSupportedException();
        public override void Write(byte[] buffer, int offset, int count) => throw new NotSupportedException();
    }

    internal class PipeWriter(Pipe pipe) : Stream
    {
        public override bool CanRead => false;
        public override bool CanWrite => true;
        public override bool CanSeek => false;
        public override long Length => throw new NotSupportedException();
        public override long Position { get => throw new NotSupportedException(); set => throw new NotSupportedException(); }

        public override void Write(byte[] buffer, int offset, int count)
        {
            lock (pipe._buffer)
            {
                pipe._buffer.Position = pipe._buffer.Length;
                pipe._buffer.Write(buffer, offset, count);
            }
            pipe._dataAvailable.Release();
        }

        public override async Task WriteAsync(byte[] buffer, int offset, int count, CancellationToken ct)
        {
            lock (pipe._buffer)
            {
                pipe._buffer.Position = pipe._buffer.Length;
                pipe._buffer.Write(buffer, offset, count);
            }
            pipe._dataAvailable.Release();
            await Task.CompletedTask;
        }

        public override void Flush() { }
        public override int Read(byte[] buffer, int offset, int count) => throw new NotSupportedException();
        public override long Seek(long offset, SeekOrigin origin) => throw new NotSupportedException();
        public override void SetLength(long value) => throw new NotSupportedException();
    }
