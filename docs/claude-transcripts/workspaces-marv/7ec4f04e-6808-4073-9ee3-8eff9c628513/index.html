3 edit · 1 read · 1 bash

Updated docs/formatting-research.md with the example analysis. The key finding: IRC formatting is stateful (like a terminal), not structural (like HTML). Your example message uses color codes as state changes that bleed across segments, never resetting between them. This means:

  • Sopel-style wrap-and-reset (Color("text", fg)) fights the natural pattern -- it'd insert redundant resets and require re-specifying the background on every segment.
  • Template tags (girc-style) are actually the closest semantic match to the raw protocol, but conflict with C# $"" interpolation.
  • Best fit for C#: A layered API where IrcColor.Orange emits the raw \x03 7 when used in string interpolation (stateful), while IrcFormat.Color("text", fg) is available for simple balanced cases. Your example would look like:
$"{Cyan.On(Black)}[ {Orange}Community {Cyan}] :: [{Green} Network: {Orange}NBC {Cyan}]..."
