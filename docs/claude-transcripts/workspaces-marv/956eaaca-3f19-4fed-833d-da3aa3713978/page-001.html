2	
3	All notable changes to this project will be documented in this file.

7	
8	## [Unreleased]
9	
10	### Added
11	
12	- Command prefix is now configurable via `CommandPrefix` in bot configuration
13	  (previously hardcoded to `!`), with support for multi-character prefixes
14	- `IBot.CommandPrefix` property exposes the configured prefix to plugins
15	- `[OnCommand]` attribute gains a `Prefix` property to override the bot-wide
16	  prefix on a per-handler basis (e.g. `[OnCommand("invite", Prefix = ".")]`)
17	- `IHttpClientFactory` is now registered by default, so plugins can inject it
18	  without adding the `Microsoft.Extensions.Http` package themselves
19	- `[OnCommand]` and `[OnRegex]` attributes gain `ChannelOnly`, `DirectOnly`,
20	  and `Channel` filter properties for declarative message context filtering
21	- Bot automatically sets bot user mode (e.g. `+B`) when the server advertises
22	  the `BOT` ISUPPORT token
23	- `UserModes` config option to set additional user modes after authentication
24	  (e.g. `"+ix"`), applied before the ready signal
25	- Server MOTD is now available via `IServerInfo.Motd` after connection
26	- `IBot.JoinMultipleAsync` sends a single comma-separated `JOIN` command per
27	  RFC 2812, with automatic batching to stay within the 512-byte line limit
28	- Handler filter pipeline: plugins can intercept handler invocations via
29	  `FilterHandlerAsync` override or declarative `IFilteringAttribute` +
30	  `IFilterEvaluator` pairs for cross-cutting concerns like authorization,
31	  rate limiting, and auditing
32	- New `Marv.Testing` package with fluent builders for `CommandContext`,
33	  `RegexMatchContext`, and events, plus `PluginTestHarness<T>` for
34	  creating plugin instances with mocked dependencies in ~2 lines
35	- `docs/PLUGIN_API.md` — consolidated plugin API reference covering all
36	  handler attributes, context types, events, IBot, formatting, configuration,
37	  services, handler groups, filters, and testing patterns
38	- `docs/PLUGIN_PROJECT_CLAUDE.md` — CLAUDE.md template for downstream
39	  plugin projects
40	- Old `plugin-api-draft.md` archived to `docs/archive/` with redirect
41	- `IBot` gains convenience methods for common IRC actions: `KickAsync`,
42	  `SetTopicAsync`, `InviteAsync`, `SetModeAsync`, `GiveOpAsync`,
43	  `RemoveOpAsync`, `GiveVoiceAsync`, `RemoveVoiceAsync`, `ChangeNickAsync`
44	- `IBot.CaseComparer` exposes the server's IRC case mapping as an
45	  `IEqualityComparer<string>` for correct nick/channel comparisons
46	- New `Marv.Plugins.Moderation` example plugin demonstrating advanced API
47	  patterns: typed configuration, declarative auth filters, event handling,
48	  interval timers, bot action methods, case-mapped collections, handler groups,
49	  raw message handling, and `SendAndAwaitAsync`
50	
51	### Changed
52	
53	- Initial channel join on connect now uses bulk `JOIN` instead of individual
54	  commands per channel, reducing startup traffic and rate-limit pressure
55	
56	- Updated Microsoft.Extensions.* packages from 10.0.0-preview.4 to 10.0.8 (stable)
57	- Updated Microsoft.NET.Test.Sdk from 17.14.0 to 18.6.0
58	- Updated xunit.runner.visualstudio from 3.1.0 to 3.1.5
59	
60	### Fixed
61	
62	- Boolean CLI options (e.g. `--use-tls`, `--rate-limit-enabled`) no longer
63	  override config file values when not explicitly provided on the command line
64	- Nullable string config properties (e.g. `TlsCaCertFile`, `SaslUser`) no
65	  longer become empty strings when set to `null` in JSON config files
66	
67	## [0.1.0] - 2026-06-01
68	
69	### Added
70	
71	- IRC client with IRCv3 capability negotiation (SASL, multi-prefix, message-tags, labeled-response, and more)
72	- Plugin system with dependency injection, inter-plugin services, and typed configuration
73	- Bundled plugins: Greet, Auth, AuthConsumer, CannedResponses
74	- Configuration layering: JSON/YAML/XML files, environment variables, CLI arguments
75	- Outbound rate limiting with configurable token bucket
76	- TLS support with optional certificate validation skip and custom CA certificate
77	- SASL PLAIN authentication and NickServ/OPER authentication with configurable timeout
78	- Optional Sentry error reporting
79	- Dockerfile for containerized deployment
