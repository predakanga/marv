v0.2.0

This release focuses on plugin developer experience — making plugins easier to write, test, and document.

Highlights

  • Configurable command prefix — The ! prefix is no longer hardcoded. Set CommandPrefix in config, or override per-handler with [OnCommand("invite", Prefix = ".")].
  • Handler filter pipeline — Plugins can intercept handler invocations for cross-cutting concerns like authorization, rate limiting, and auditing, using either FilterHandlerAsync or declarative IFilteringAttribute/IFilterEvaluator pairs.
  • Declarative message filters — [OnCommand] and [OnRegex] now support ChannelOnly, DirectOnly, and Channel properties to restrict where handlers fire.
  • Bot action methods — IBot gains convenience methods for common IRC operations: KickAsync, SetTopicAsync, InviteAsync, SetModeAsync, GiveOpAsync/RemoveOpAsync, GiveVoiceAsync/RemoveVoiceAsync, ChangeNickAsync.
  • IRC case mapping — IBot.CaseComparer exposes the server's case mapping as an IEqualityComparer<string> for correct nick/channel comparisons.
  • Test infrastructure — New Marv.Testing package with fluent builders and PluginTestHarness<T> for writing plugin unit tests in ~2 lines of setup.
  • Plugin API docs — Consolidated docs/PLUGIN_API.md reference covering attributes, contexts, events, configuration, services, filters, and testing.
  • Moderation example plugin — Demonstrates advanced patterns: typed config, auth filters, event handling, interval timers, bot actions, case-mapped collections, handler groups, and raw message handling.

Other changes

  • Bulk JOIN on connect reduces startup traffic and rate-limit pressure
  • Automatic bot user mode (+B) when the server advertises the BOT ISUPPORT token
  • IHttpClientFactory registered by default for plugins
  • UserModes config option and IServerInfo.Motd access
  • Dependencies updated to stable Microsoft.Extensions.* 10.0.8
  • Fixed boolean CLI options and nullable string config properties not round-tripping correctly
